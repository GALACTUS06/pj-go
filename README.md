# PJ Go (temporary name)

Location-based exploration game for **Port Jefferson, NY**.

Walk a compact **3D white-box harbor map**, visit fixed checkpoints, collect **9 puzzle pieces**, and reveal the **Port Jefferson ↔ Bridgeport ferry** finale image.

| Mode | How the avatar moves |
|------|----------------------|
| **Virtual** (required) | On-screen controls — full game completable |
| **Live** (optional) | Device GPS drives avatar position |

Stony Brook campus prototype archived separately: [`GALACTUS06/sb-go`](https://github.com/GALACTUS06/sb-go) tag `sbu-archive-v0.1.5`.
